# md-preview 示例报告

> 本文档用于演示 md-preview 扩展的真实预览与「选中提问 → Agent 回复」闭环。

## 功能概览

- 目录导航（TOC）
- 代码高亮
- 明亮 / 黑暗主题
- 字号调节（0.8×–1.6×）
- 源文件修改后页面自动刷新
- 选中正文文本，弹出「✦ 提问」按钮，提问直达当前 pi 会话

## 关键指标

| 指标 | 数值 | 说明 |
|---|---|---|
| 冷启动耗时 | 120 ms | 本地 HTTP 服务 |
| 端到端刷新延迟 | <300 ms | 文件监听 + SSE 推送 |
| 主题切换 | 即时 | CSS 变量热切换 |

## 快速上手

```bash
pi install ./local-package   # 安装扩展
pi -c                        # 恢复会话后调用 md_preview 工具
```

任务清单：

- [x] 预览服务随标签页关闭自动退出
- [x] 提问 → 会话 → 回复（SSE）闭环
- [ ] 更多主题

## 技术细节

预览页为无依赖的单个 HTML 字符串：Markdown 经 `marked` 渲染后内联
TOC、主题偏好与问答数据，事件流（SSE）负责推送文档更新与问答卡片。

```ts
server.onAsk = (qa) => sessionMessenger?.(formatAskMessage(qa));
```

## 下一步计划

1. 在预览页里**选中任意一段文字**
2. 点击弹出的「✦ 提问」按钮，输入问题并发送
3. Agent 会在会话中收到提问并调用 `md_preview_reply` 回复
4. 回复卡片实时出现在页面左侧
