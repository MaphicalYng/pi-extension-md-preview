# 已读位置高亮示例

这份文档用于演示：侧边栏的长回复展开后，如何快速找到继续阅读的位置。

## 操作步骤

1. 找到文档左侧的 Agent 回复卡片。
2. 卡片中的回复只显示前 6 行，点击下方的「查看全文」。
3. 弹窗里带有浅黄色背景的部分，就是刚才卡片已经显示的内容。
4. 从没有背景色的第一段文字开始继续阅读即可。

## 示例段落

**已读位置高亮**适合阅读较长的分析、方案说明和分步指导。它不改变回复原文，也不要求用户记住折叠前的最后一个词。

你可以调整浏览器窗口宽度或页面字号，再次点击「查看全文」。高亮终点会根据当前卡片实际显示的内容重新计算。

## 可以检查的细节

- 高亮可以跨越段落、粗体、链接和行内代码。
- 重复关闭、打开弹窗，不会重复叠加高亮。
- 弹窗每次都会回到顶部，方便对照已读与未读内容。
- 短回复不会出现「查看全文」按钮。
